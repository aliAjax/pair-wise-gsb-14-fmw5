# 批发锁价与信用占用台（油品价格维护扩展）

- 行业：石油（批发）
- 技术栈：Vue3、Vite、TypeScript、Pinia（无新增依赖，界面样式为原生 CSS）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **报价单登记**：客户、油品、锁定价、数量、生效区间、经办人；登记即带 v1 价格快照进入**草稿**。
2. **时段互斥**：同客户同油品的报价单生效区间（闭区间，端点相接也算）不得重叠；登记预警计入草稿占位，生效复核只拦截已生效合同。
3. **审批依据**：锁定价低于油品成本线、或生效后将超出客户授信额度时，必须填写审批依据与审批人；否则**整单留草稿**，补齐后通过"编辑草稿"可再次提交。
4. **授信占用**：只有合同**生效**才按「锁定价 × 数量」冻结占用授信；**撤回立即释放**，**到期（结束日早于业务日期）自动回退**。
5. **价格冻结与版本链**：生效后锁定价冻结，改价不覆盖原值，必须带原因/经办人追加为新版本；授信冻结额保持生效快照，不随后续改价变化。
6. **刷新一致性**：每次加载与"刷新并对账"都会重算到期回退、授信占用、冲突与版本链展示；冲突清单逐行列出**客户、油品、数量、额度**（时段重叠 / 授信超限两类）。

## 分层结构（数据 / 规则 / 存储 / 界面分开）

```
src/
├── types.ts                 # 领域模型（纯类型，无逻辑）
├── data/seed.ts             # 数据层：内置种子数据
├── rules/
│   ├── domain.ts            # 规则层：校验、审批、生效/撤回/到期、改价版本（纯函数）
│   └── conflicts.ts         # 规则层：授信汇总与冲突行推导（纯函数）
├── storage/localStore.ts    # 存储层：localStorage 读写与版本迁移
├── stores/quoteStore.ts     # Pinia 编排：调用规则 → 落盘存储，组件不直接碰 localStorage
├── components/              # 界面层：QuoteForm / QuoteList / QuoteCard / CreditPanel / ConflictPanel
└── App.vue
```

数据默认保存在浏览器 localStorage（键名 `dfwlfront-9-lock-price-v1`），"恢复演示数据"可一键还原种子。
