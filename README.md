# 批发锁价与信用占用台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia（无新增依赖，界面使用原生控件与自有样式）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在"油品价格维护"基础上扩展的批发锁价与授信风控闭环，数据默认保存在浏览器 localStorage。

## 业务规则

- 报价单登记客户、油品、锁定价、数量、生效区间；登记后整单先入草稿。
- 同一客户同一油品的生效区间不得重叠（与生效中或草稿单重叠即阻断）。
- 锁定价低于油品成本线、或生效首日将超出客户授信额度时，必须填写审批依据，否则整单留草稿无法生效。
- 合同生效才占用授信，并写入 v1 价格冻结快照；撤回立即释放授信；超过生效止日期的单子刷新时自动到期回退、释放授信。
- 生效后锁定价/数量冻结，任何改动必须填写变更原因并另存一个价格版本，形成版本链；生效区间不可改。
- 刷新后报价状态、授信占用、版本链保持一致；冲突台固定列出客户、油品、数量、涉及额度与说明。

## 分层结构

- `src/types.ts`：数据模型（纯类型）
- `src/rules.ts`：业务规则（纯函数：重叠判定、授信测算、到期回退、校验、冲突扫描）
- `src/storage.ts`：localStorage 持久化与种子数据
- `src/store.ts`：Pinia 状态层，编排规则与存储
- `src/components/*` 与 `src/App.vue`：界面层
